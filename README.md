# Clauder Launcher

Windows PowerShell launcher UI for a separately installed Claude Code CLI; explicit local mode selection.

Windows PowerShell launcher around a separately installed Claude Code CLI. It presents
local working-folder, plugin/skill and permission-mode choices; local launcher-state.json is private.
Read both scripts before use. Install-DesktopShortcut.ps1 creates a desktop shortcut when explicitly
run. Launch-Claude.ps1 can update/install CLI/plugin components and launch an interactive session.
Permission bypass/skip options are explicit operator choices and are not verification modes.
No provider account, API credential, local state or CLI binary is included.

See VALIDATION.md for actual checks.
